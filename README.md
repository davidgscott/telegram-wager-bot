The Telegram DIVI_Wager_ Bot is a telegram bot that allows channel member to vote (or wager) on the value of a cryptocurrency by a specific deadline. 
It uses the CoinGecko API to check the price at the resolution time.
The goal is to create a binary yes/no wager, much like predictive trading.  
It's a fun engagement tool that doesn't involve money, but tracks wins and losses on a postgres database leaderboard and ranks them by a powerscore.
The leaderboard will rank all time leaders and monthly leaders, creating some sense of competition.
Future development may include functionality for running contests, wagers on non-crypto events, or wagers on stock tickers.
